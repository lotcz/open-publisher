# Open Publishing

Platform for publishing articles to multiple destinations (websites).

## DB migrations

Flyway migrates database automatically on application start.

## Debugging

Start dev db:

    .\bin\start-dev-db.cmd

Start server debugging

    .\bin\debug-server.cmd

API documentation:

    http://localhost:8090/swagger-ui/index.html

UI development:

    .\bin\debug-ui.cmd
